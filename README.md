# Aemro Guitarist Portfolio

A responsive portfolio website for guitarist Aemro, featuring performance
videos, biography, gear, an interactive Ethiopian scale sampler, and booking
contact details.

## Local development

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

The local site runs at `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```

The production frontend is generated in `dist/`.
